# Roomly — Sistema de Agendamento de Salas

O **Roomly** é um sistema web de agendamento e gerenciamento de salas de coworking, desenvolvido para facilitar a reserva de espaços, a consulta de disponibilidade e a organização dos agendamentos.

O projeto tem como objetivo oferecer uma experiência simples, intuitiva e eficiente para usuários e administradores de espaços compartilhados.

> 🚧 **Status: Em desenvolvimento**
>
> O projeto está atualmente em sua fase inicial de **modelagem de dados, planejamento da arquitetura e prototipagem das interfaces**. As funcionalidades e integrações ainda serão desenvolvidas.

## Tecnologias

O projeto utilizará as seguintes tecnologias:

### Backend
- **TypeScript** — Linguagem de programação.
- **NestJS** — Framework para construção de APIs escaláveis e modulares.
- **PostgreSQL** — Banco de dados relacional.

### Frontend
- **React** — Biblioteca para construção de interfaces.
- **TypeScript** — Tipagem estática e maior segurança no desenvolvimento.

### Modelagem e prototipagem
- **dbdiagram.io** — Modelagem e representação do banco de dados.
- **Prototipagem de interfaces** — Planejamento da experiência do usuário e das telas da aplicação.


## Banco de dados

O Roomly utilizará **PostgreSQL** para persistência dos dados.

A modelagem inicial está sendo realizada por meio do **dbdiagram.io**, permitindo definir entidades, relacionamentos e restrições antes da implementação da camada de persistência.

## Arquitetura

A aplicação será dividida em duas partes principais:

**Backend — NestJS + TypeScript**

Responsável pelas regras de negócio, autenticação, gerenciamento das reservas, validação de disponibilidade e comunicação com o banco de dados.

**Frontend — React + TypeScript**

Responsável pela interface web, navegação, visualização das salas e interação dos usuários com o sistema.

A estrutura definitiva da aplicação será estabelecida durante a evolução do desenvolvimento.


## Objetivo do projeto

O Roomly também tem como propósito aplicar boas práticas de engenharia de software, modelagem de dados, desenvolvimento de APIs REST e construção de interfaces modernas, utilizando tecnologias do ecossistema TypeScript.
